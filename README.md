# 📌 Tentang Project

**Gmail-Phish** adalah project simulasi phishing berbasis Python Flask yang dibuat untuk tujuan pembelajaran cyber security secara etis.

Project ini menunjukkan bagaimana teknik phishing dan social engineering bekerja dalam meniru halaman login agar pengguna memahami:

* Cara kerja phishing
* Teknik manipulasi visual
* HTTP POST Request
* Struktur fake login page
* Pentingnya awareness terhadap ancaman phishing

# ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/mrone61/Gmail-Phish.git
cd Gmail-Phish
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run Program

```bash
python gphis.py
```

# 🚀 Usage

Setelah program dijalankan, server akan berjalan di:

```txt
http://127.0.0.1:8080
```

### Simulasi Workflow

```txt
1. User membuka halaman login simulasi
2. User memasukkan email dan password
3. Form mengirim POST request
4. Server memproses input
5. User diarahkan ke halaman lain
```
